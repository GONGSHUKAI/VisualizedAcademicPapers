Harness for Robotics

Harness 指包在模型外面（或模型内部）的那层执行框架：每一步让模型看到什么、跨步记住什么、任务怎么拆、拆完以什么接口交给下一层、执行时用什么信号判断对错、判断之后改什么。本专题按这个视角读机器人基础模型的论文。

本页按四类收录 11 篇：（1）上下文架构（ActiveVLA、TIC-VLA、RA-VLA）、（2）持久状态与记忆（MemoryVLA、OptimusVLA、SOMA、HiMe）、（3）结构化执行（ACoT-VLA、MotorMind）、（4）评估与反馈（TT-VLA、τ₀-VLA）。每篇有单独的精读页，下面是四类的定义、各篇的位置、索引和横向对照。

四类 harness

分类按专题定义，每篇归入一类，归类取它们的主要贡献。有几篇跨类：SOMA 的记忆要靠一次主动扫描才建得起来，和（1）的「看哪里」耦合；OptimusVLA 的全局记忆其实是跨回合的轨迹检索，机制上接近 RA-VLA；τ₀-VLA 与 MotorMind 都带执行记忆，也沾（2）。

（1）

上下文架构 Context Architecture

设计模型每次决策时看到什么、以什么形式看到，包括检索、视觉选择、时序对齐等。

  • ActiveVLA：视觉选择。在已重建的点云上挑虚拟视点、放大，决定 VLM 看哪几张图。
  • TIC-VLA：时序对齐。慢 VLM 的结果带着「多旧了、期间走了多远」交给快控制器。
  • RA-VLA：检索。按动作阶段从新任务示范里取片段，喂进动作头。
（2）

持久状态与记忆 Persistent State / Memory

在多步任务中持续保存任务状态、空间状态和执行历史，使当前动作不只依赖于当前 observation。

  • MemoryVLA：执行历史。VLM 与动作头之间按时间累积的特征记忆库。
  • OptimusVLA：执行历史与跨回合先验。检索来的轨迹和已执行的动作块都接在去噪起点上。
  • SOMA：空间状态。视野外的物体写成带 3D 框的物体 token。
  • HiMe：任务状态。策略之外的图文记忆和子任务计划表，由大模型增改删。
（3）

结构化执行 Structured Execution

把复杂任务组织为「推理 → 意图/子任务 → 动作」的分层受控执行流程，通过明确的中间接口连接高层决策与低层控制。

  • ACoT-VLA：接口在模型内部，是一段动作空间里的粗参考轨迹。
  • MotorMind：接口全在模型外部，是带成功判据的子目标和带数值的中层动作 JSON。
（4）

评估与反馈 Evaluation & Feedback

在执行前或执行后引入显式评价信号，根据结果修正计划、更新状态或适应策略，形成闭环。

  • TT-VLA：执行后，用进度估计的差分做奖励，在回合内更新策略参数。
  • τ₀-VLA：执行前，用世界模型想象候选子任务的后果、价值模型打分，再提交。

ActiveVLA

Injecting Active Perception into Vision-Language-Action Models for Precise 3D Robotic Manipulation

做法
沿用 BridgeVLA（PaliGemma）的「2D 热图 → 3D」框架做两遍：粗阶段在三张正交投影上找关键 3D 点 pf；再在以 pf 为球心的测地球面上，按可见性、距离、多样性的 Z 分数挑 3 个虚拟视点，对最佳视点把视场角缩小 4 倍再渲染一张，精阶段只看这些图。选视角和放大都没有可学习参数，物理相机不动。
结果
RLBench 18 任务平均 91.8（BridgeVLA 88.2），COLOSSEUM 65.9（64.0），GemBench 51.3（50.0）。消融里两个模块合计 +2.3~+4.2 个点，推理时间约翻倍（RLBench 0.26 → 0.53 s）。
疑点
按正文公式，候选都在同一球面上，距离项和多样性项对每个候选都是常数，排序只剩二值的可见性。只选 1 个主动视图（82.2）反而低于固定视图（87.6）。真机平台、COLOSSEUM 分项、真机总成功率在正文和附录里各有两套说法。

TIC-VLA

A Think-in-Control Vision-Language-Action Model for Robot Navigation in Dynamic Environments

做法
慢 VLM（InternVL3-1B，看 t−Δt 时刻往前 9 s 的 4 帧，生成推理文本和 3 个航点）在后台异步运行；10 Hz 的 6 层交叉注意力动作专家读当前帧、速度、VLM 最后一层 KV cache，外加延迟 Δt 和这段时间的自身位移 Δp。三阶段训练：VLM SFT → 动作专家模仿学习，人为注入 Δt ~ U(0,10) s → 仿真里 PPO，VLM 真异步运行。
结果
DynaNav 85 条 SR 55.29（最强语言导航基线 MobileVLA 32.94，点目标的 NavDP 54.12）。同样的 KV 接口，不建模延迟 30.59、建模后 47.06（均未做 RL）。Unitree Go2 真机 4 个任务各 5 次，0.75–0.85。
疑点
模仿学习时的 KV 由 GPT-5 标注的推理文本算出（标注时看过未来画面），部署时换成 VLM 自己生成的文本。「有效延迟」前后两处定义不同。85 条测试只跑一个种子，和 NavDP 只差 1 条。

RA-VLA

Retrieval-Augmented VLA for Test-Time Adaptation

做法
GR00T N1.5 外挂检索：新任务的 3–4 条示范切成片段（某一时刻的观测 + 其后 16 步动作），由冻结 VLM 离线预编码。检索器用 DTW 对齐的动作序列定义正样本做对比学习，按「动作阶段」而不是画面相似度取片段；动作头 8 个交叉注意力层每层拼一段检索特征，去噪起点换成检索动作的均值，再用 margin 损失逼动作头读检索结果。新任务不更新权重。
结果
LIBERO 留出套件平均 0.3845（RICLR 0.2085、RAEA 0.1235，都换上了本文的检索器）；UR5e 4 任务留一法 0.5625（0.3542）。K = 8 时单个动作块 0.055 s，RAEA 0.157 s。
疑点
LIBERO-Goal 上去掉 margin 损失只剩 0.098、换回现成检索器只剩 0.102，都回到 RAEA（0.104）的水平。去噪起点这一项没有消融。附录「107 个键检索 0.18 ms」按显存带宽算不通。UR5e 合并后 27/48 对 17/48，Fisher 检验 p ≈ 0.065。

MemoryVLA

Perceptual-Cognitive Memory in Vision-Language-Action Models for Robotic Manipulation

做法
CogACT 骨架（7B Prismatic VLM + 约 300M DiT 动作头）中间插一个感知-认知记忆库：每步存 256 个感知 token 和 1 个认知 token（LLaMA 在 EOS 处的隐状态），当前 token 作 query 对记忆做 cross-attention 检索，经 sigmoid 门与当前 token 融合后送动作头并写回。每条流最多 L 条（16 或 256），满了合并相邻最相似的一对。输入只有单帧第三人称 RGB。
结果
SimplerEnv-Bridge 71.9（复测的 CogACT-Large 57.3），Fractal 72.7（68.1），LIBERO 96.5（93.2），Mikasa-Robo 41.2；真机时序任务 83（CogACT 57）。RTX 4090 单次推理 0.194 s，基线 0.187 s。
疑点
没有「同一套训练、只去掉记忆」的对照。仿真报的是在测试基准上最好的那个验证步，基线是单个发布权重。正文说 Mikasa 上「每个任务都最好」，表里有两个任务不是。

OptimusVLA

Global Prior Meets Local Consistency: Dual-Memory Augmented Vision-Language-Action Model for Efficient Robotic Manipulation

做法
冻结的 π0.5 外挂两块记忆，都接在 flow 的去噪起点上。GPM 按 VLM 前缀检索训练集里的同类轨迹，按任务进度各切一个动作块，矩匹配成对角高斯来代替 𝒩(0, I)，相似度同时决定噪声尺度和去噪步数；LCM 用 Mamba 读本回合已执行的动作块，输出一个偏置加到起点上。VLM 输入和动作头条件都不变。
结果
LIBERO 平均 98.6（π0.5 96.9），LIBERO-Long 96.4（92.4）；CALVIN Avg. Len 4.45（π0.5† 4.26）；RoboTwin 2.0 Hard 主表 8 任务 38%（29%）。NFE 3.2 对 10，LIBERO 单次推理 39 ms 对 57 ms。
疑点
摘要的「2.9× 推理加速」是真机 NFE 之比，对 π0.5 的实测时间比是 1.46×（LIBERO）和 1.19×（真机）。flow policy 只在高斯起点上训练过，没有「高斯起点直接走 3–4 步」的对照。RoboTwin 全部 16 个任务是 30%。

SOMA

Spatial Memory for Out-of-Vision Manipulation in Vision-Language-Action

做法
GR00T N1.5 式 VLA 外挂物体级空间记忆：目标不可见时，可动头部按固定轨迹扫一圈，YOLO-World 检测、DINOv3 取外观、VGGT 算 3D 框，每个物体压成一个 384 维 token；操作中用头部画面做 α = g·s 的门控 EMA 刷新，VL token 对全部记忆做交叉注意力，结果作为 DiT 的额外上下文。
结果
5 个视野外真机抓放任务各 20 回合，各阶段平均成功率 28.3%（按图 4 算，GR00T N1.5 18.3%）。RoboCasa GR1（目标全可见）用全部数据时 49.3 对 45.9。在线推理约 1.58 s / 动作块（GR00T N1.5 约 1.30 s）。
疑点
表 2 有几个数用「20 回合 × 阶段平均」算不出来。GR1 消融的增益几乎全来自「容器交互」一类。行为指标的定义和正文的解读对不上。记忆条目不带时间戳，被挪走的物体会留下陈旧条目，论文承认但没有实验。

HiMe

Hierarchical Embodied Memory for Long-Horizon Vision-Language-Action Control

做法
三层、三种频率：Executor（π0.5，推理 2 Hz）只看当前画面和一句子目标；Sentry（Qwen3-VL-8B）每 10 个执行步看一眼最近 8 帧，判当前子任务是否完成；判完成才唤醒 Planner（GPT-4o），它用 QUERY / CREATE / UPDATE / DELETE 增改删一个图文键值记忆库，并重写子任务计划表。只有 Executor 需要训练（60 条示范）。
结果
WidowX-250 三个长程任务（各 20 次），平均任务进度 90；去掉 Sentry 68，FIFO 式 Flat Memory 65，无记忆 14。每个子任务 Planner 调用 1.4–2.6 次（Flat Memory 4.8–6.2 次）。
疑点
「90」是子任务完成比例，不是整任务成功率。Sentry 判完成的召回约 35%，靠一个间隔没写的定时兜底。GPT-4o 单次调用中位 38.59 s，比一个子任务的平均执行时长还长，全文没有整任务耗时。换成 Qwen3-VL-30B 后有两条结论与正文相反。

ACoT-VLA

Action Chain-of-Thought for Vision-Language-Action Models

做法
π0.5 上加三块：EAR（18 层、约 300M，读 VLM 逐层 KV，用 flow matching 生成步长 2、15 点的参考轨迹）、IAR（每层 1 个 query，在降到 128 维的 KV 上抽隐式先验）、AGP（加噪动作当 query 交叉注意力读两路）。训练时参考轨迹用真值（teacher forcing）。
结果
LIBERO 98.5（π0.5 96.9）；LIBERO-Plus 零样本 86.6 vs 85.7、微调 88.0 vs 75.7；真机 4 项平均 66.7% vs 61.0%。同参数量同步数下，拆成「EAR + 动作头」比单个大动作头在 LIBERO-Plus 上高约 8 个点。
疑点

（1）（2）里的线索解读

按各篇精读页整理，数字取自各论文的 tex 表格。

看不见的东西：换个视角，还是记下来？

ActiveVLA 在已经重建的点云上重渲染虚拟视点，物理相机不动，能看到的上限是已经拍到的点；SOMA 真的转动头部相机扫一圈，把视野外的物体写进记忆。前者每个关键帧重新选、不留状态；后者扫描一次、之后靠门控刷新，代价是被挪走的物体会留下陈旧条目（论文承认，没有实验）。

记忆存成什么？

MemoryVLA 存特征 token，按时间排、满了合并；OptimusVLA 存动作，一边是跨回合的轨迹库，一边是本回合已执行的动作块；SOMA 存物体 token，按物体索引、不带时间戳；HiMe 存人可读的图文记录，由大模型增改删。前三篇的记忆在策略的一次前向里被读，HiMe 的记忆只经一句子目标进入 π0.5。

记忆本身贡献多少，证据不齐

MemoryVLA 没有「同一套训练、只去掉记忆」的对照，只能和复测的 CogACT 比；SOMA 在 GR1 上的消融增益几乎全来自「容器交互」一类；OptimusVLA 去掉 GPM / LCM 后 LIBERO-Long 从 96.4 降到 93.2 / 94.8；HiMe 在同一层级骨架下比了无记忆（14）和 FIFO 式记忆（65），对 90，四篇里最直接。

加上 harness 的代价

ActiveVLA 每次推理约翻倍（RLBench 0.26 → 0.53 s）；SOMA 每个动作块 1.30 → 1.58 s；MemoryVLA 0.187 → 0.194 s；OptimusVLA 反而更快（57 → 39 ms），因为去噪步数从 10 降到 3.2；HiMe 的 GPT-4o 单次调用中位 38.59 s，整任务耗时没有报告。各篇计时口径不同，只能各自和自己的基线比。

跨类的线索解读

（1）（2）的七篇和（3）（4）的四篇放在一起看。

「子任务做完没有」是共同的薄弱点

HiMe 的 Sentry 判完成，精确率约 82%、召回约 35%（正文数字，对应原文图 7）；MotorMind 的诊断里六个通用 VLM 判完成只有 47.5–82.5%（二分类），扰动设定下 9% 的回合错误宣布完成；τ₀-VLA 不测判别器，而是用记忆滞后、超前、未察觉失败三类扰动样本训练纠错。下面「评价器本身可靠吗」一条说（3）（4）三篇都没评估评价器，HiMe 是在自己任务上量过的一篇。

异步分层里，只有 TIC-VLA 告诉低层上下文有多旧

τ₀-VLA 的低层读约每 1 s 刷新的子任务缓存，搜索没算完时按旧子任务执行；HiMe 等 GPT-4o 的那几十秒里机器人怎么办没有写；MotorMind 主线串行。TIC-VLA 的「同一个 KV 接口，不建模延迟 30.59、建模后 47.06」是 11 篇里唯一直接说明延迟要显式建模的对照。

给动作头一段动作先验，怎么逼它读？

RA-VLA 读别人同一动作阶段的动作块，并用它们的均值当去噪起点；OptimusVLA 用检索到的训练集轨迹当起点；ACoT-VLA 读自己的 EAR 生成的 15 点粗轨迹。逼动作头读的办法分别是 margin 损失（去掉后 LIBERO-Goal 0.532 → 0.098）、只在推理时换起点（flow 只在高斯起点上训练过）、teacher forcing。ACoT-VLA 和 OptimusVLA 用同一个 π0.5 基线（LIBERO 96.9，Long 92.4），提升都集中在 Long。

「测试时适应」至少有三种意思

RA-VLA 不改权重，往库里放新任务的几条示范，每个动作块检索一次；TT-VLA 在回合内每 8 步更新一次 LoRA，下个回合重置；τ₀-VLA 把测试时的算力花在子任务搜索上。TT-VLA 只适用于离散 token 的自回归 VLA，（1）（2）类七篇的动作头都不在它的适用范围内。

（3）（4）里的线索解读

语言子任务够不够细？

ACoT 和 MotorMind 都认为「子任务文本 → 动作」这一跳太大，一个在模型里多生成一段动作草稿，一个让 VLM 直接说出带数值的动作。τ₀ 仍用语言子任务，但它处理的是分钟级任务，问题不在接口粒度，而在选哪个子任务。三者处理的是不同时间尺度，可以叠加。

评价器本身可靠吗？

MotorMind 的诊断里，通用 VLM 判断进度的准确率只有 43–76%，扰动设定下还有 9% 的回合「宣布完成但其实没完成」。TT-VLA 的奖励完全来自 VLAC 的进度估计，τ₀ 的打分完全基于世界模型的想象。三篇都没有直接评估评价器在自己任务上的准确率。

执行前，还是执行后？

τ₀ 在承诺前评价，代价是要训练世界模型、只能评价想象；TT-VLA 和 MotorMind 在承诺后评价，代价是错误已经改变了环境。τ₀ 的引言把这一点说得很直接：重规划可以响应，但收不回失败承诺的代价。

统计强度普遍偏弱

四篇的真机实验每格 10–40 次，仿真里 TT-VLA 每格 240 次但增益只有 1–4 个点。都没有报告方差或显著性检验。读结论时，看试验次数比看百分比更重要。
