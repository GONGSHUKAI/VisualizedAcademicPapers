ForceVLA

Enhancing VLA Models with a Force-aware MoE for Contact-rich Manipulation

做法
π0 本身不改。6 维末端力/力矩投影成 1 个 token，在 VLM 之后和视觉语言 token 一起经过一层注意力和一个 4 专家 MoE（FVLMoE），结果加到动作 token 上。
结果
5 个真机接触任务平均成功率 60.5%，不接力的 π0 为 37.3%。融合位置消融里，VLM 之前用 MoE 融合是 0%，VLM 之后用 FVLMoE 是 80%。
疑点
没有单独去掉 MoE 的消融，收益分不清来自路由还是新增的注意力层。部分成功率和所述试验次数对不上，比如写的是 20 次试验，图里却有 83%。

Tactile-VLA

Unlocking Vision-Language-Action Model's Physical Knowledge for Tactile Generalization

做法
最近 H 步触觉经 MLP 压成 1 个 token 放进 VLM 前缀。动作同时输出目标位置和目标力，由位置-力混合控制器执行。CoT 变体用触觉做语言推理，失败时写出新的纠正指令。
结果
插 USB 35%、插充电器 90%（π0-base 为 5% / 40%）。没训过的力度词也能对应出不同施力。训练中没见过的黑板上擦除，CoT 版 80%，不带 CoT 的 15%。
疑点
基线本身不输出力，所以分不清成功来自「VLM 先验里的物理语义」，还是来自「多了力通道和控制器」。多张表没写试验次数，文中至少 4 处前后不一致。

T-Rex

Tactile-Reactive Dexterous Manipulation

做法
Qwen3-VL-2B 的三专家 MoT：latent 专家预测未来视觉潜变量，动作专家把动作从 τ=1 去噪到 0.4，0.62B 的触觉专家复用缓存的 KV，在一个 16 步动作块内于第 0/4/8/12 步各用最新触觉走完最后 4 步。触觉 = 逐指 VQ-VAE 力 token + 当前 6 维力 + 冻结 CNN 的形变图特征。人类视频预训练 → 100 小时触觉中训练 → 单任务后训练。
结果
12 个双臂灵巧手真机任务平均 65，EgoScale 35、π0.5 17、Tactile-VLA 15；6 任务上去掉触觉 65 → 42，同步版本 60。
疑点
分数是按细则给部分分的进度分；只有 T-Rex 用了 100 小时中训练数据，按同 6 个任务换算，架构本身比 EgoScale 高约 9 分。反应频率和时延没有实测。

N₀-VTLA

Scaling Vision–Tactile–Language–Action Model with Latent Tactile Tokens

做法
π0.5 上加一条通路：冻结 DINOv2 编码触觉差分图，小预测器结合视觉语言上下文输出 10 个潜在触觉 token z，拼在动作 token 前。三阶段接入：只训预测器（InfoNCE 对上未来 50 步触觉变化）→ 屏蔽前缀逼动作专家读 z → 端到端。另有离线 RL 方法 ALTER。
结果
NeoReal 9 个真机任务全胜，均值 47.2% vs π0.5 29.4%；20 个仿真任务 63.8% vs 44.0%；ALTER 后三个长时程任务 95/80/75%。
疑点
没有闭环消融：三阶段 vs free-latent、预测的 z vs 当前触觉都只用检索准确率论证。π0.5 基线是否也有 NeoData 预训练没写，触觉和额外数据的贡献分不开。

N₀-TWAM

Scaling Tactile-Native World Action Model for Contact-Rich Manipulation

做法
从 LingBot-VA 改出视频（5.00B）、动作、触觉（各约 1B）三专家的非对称 MoT，每层共享一次自注意力；帧级因果掩码让块内先共同生成未来视频和未来触觉（同一个 Wan VAE 潜空间），再去噪动作。后训练加一条力空间观测通路（NeoForce + 零初始化交叉注意力）；触觉接触事件切分并推进子任务。
结果
UniVTAC 84.5（最强基线 67.1），NeoSim 49.4（π0.5 45.8），8 个真机任务 46.3（π0.5 30.0）。去掉预测通路或观测通路，NeoSim 分别降到 41.1 和 29.6。
疑点
主表 4 个仿真任务用绝对位姿、其余用 delta，按 delta 重算 NeoSim 不再领先 π0.5。消融逐任务起伏极大；没有推理时延数字。和同日的 N₀-VTLA 共用基准却不互相比较。

Motus2

A Self-Evolving General World Model for Dexterous Manipulation

做法
一个从 Wan2.2-5B 初始化的视频-动作 DiT，靠掩码和 loss 开关分别充当策略、模拟器、评估器，组成「提议 → 想象 → 打分」的闭环。触觉是一个 30 层、宽 128 的旁路专家：主干只去噪到 σ=0.2，每个 0.2 s 子块执行前由触觉专家用最新触觉完成最后一段。
结果
主结果宏平均 84%（π0.5 为 0%）。规划和 MBRL 合用 65.0% → 75.0%。加触觉专家后，两个真机任务 60.0% → 72.5%。
疑点
实验里的「自进化」只跑了一轮。每格只有 20 次试验，1 次成功就是 5 个百分点。触觉只在 2 个任务上评测。

ME-Dex 1.0

Bringing Heterogeneous Tactile Sensing into World Action Modeling

做法
视频、触觉、动作三专家 MoT，全部用 flow matching，在中间层共享注意力（H-Bridge），未来触觉和视频、动作联合去噪。Canonical Hand Model 和 Unified Tactile AE 把夹爪和灵巧手的触觉统一到同一空间；仿真里的触觉由数据引擎在轨迹回放时补录。
结果
RoboTwin 91.56 / 91.92（Clean / Random），比 Fast-WAM 高 2.34 / 2.70 个点；DexJoCo 平均 65.3，ManiFeel 70.0，都领先所比基线。
疑点
推理时把触觉置零，RoboTwin 仍有 91.70 / 91.74，几乎不变，论文自己也承认。所有实验单种子，真机只有定性展示。
