# 精读页规范

新增论文时按这份规范做页面，保证合集里的页面质量一致。读者是做机器人、生成模型方向的研究者：基础概念不用从零讲，但这篇论文的具体设计、实验和结论要讲透。

## 取材

- **读全文，包括附录**，读完再动笔。
- **用 arXiv 源码包，不要从 PDF 渲染页里裁图。** `curl -L https://arxiv.org/e-print/<id> -o src.tar.gz` 拉下 tex 源码：
  - 图用源码里的原图。矢量 PDF 图用 `pdftoppm -r 220 -singlefile -png fig.pdf out` 转成 PNG。
  - arXiv HTML 版（`https://arxiv.org/html/<id>`）里的 `<figure id>` 和图注，可以用来把图文件对上 Figure 编号。
- **数字以源码里的 tex 表格为准**，不要从 pdftotext 的输出里抄。图里的数字（例如柱状图标注）可以对矢量 PDF 跑 `pdftotext` 取。
- 论文没说的不写。数字对不上、试验次数和百分比矛盾、正文和图注不一致的地方，写进「局限与疑点」。

## 图片

- 长边不超过 1800px。照片用 JPEG，质量约 85；线图和架构图如果 PNG 更小就用 PNG。
- 一篇论文的 `fig/` 总共不超过 6 MB。没用到的图不要留。
- 每张图配中文图注，说清这张图在讲什么、应该看哪里，并标注原文的 Figure/Table 编号。

## 页面结构

按阅读顺序排：

1. **首屏**：论文名、机构、arXiv 编号和版本日期，一句话讲清核心主张。只有当几个数字确实是重点时才放数字。
2. **问题**：要解决什么，现有方法为什么不行。配 teaser 图。
3. **方法**：逐模块拆解，讲清输入输出、维度、融合发生在哪一层、训练目标和推理流程。至少做一个真正帮助理解的交互，比如可点击的架构图、数据流分步演示、注意力掩码可视化、控制律的小模拟。原文没给的细节标「未披露」，不要编。
4. **实验设置**：平台、传感器、任务、数据量、baseline、每个条件的试验次数。
5. **结果**：主表用 SVG 按比例重画，数字逐字来自论文，标上表号，每张图下可以展开看原表。然后是消融和定性结果。
6. **读懂它**：关键 insight、容易误解的点、几条 FAQ，按论文实际给出的证据来答。
7. **局限与疑点**：论文自己承认的，和我们读出来的，分开写。
8. **放到专题里看**：这篇在所属专题里的位置，和同专题其他论文的异同。写之前先读那几篇的原文或精读页。
9. **术语表**，可折叠。

## 写法

- 中文，平实直接，英文术语保留原文。
- 我们自己的判断标注「解读」，和论文的主张分开。
- 不写空话，每一段都要落到这篇论文的具体设计或数字上。

## 设计

- 每篇有自己的视觉身份（配色、展示字体），从论文主题里取材，避免千篇一律的模板感。
- 深浅两套主题：颜色全部定义成 `:root` 上的变量，在 `@media (prefers-color-scheme: dark)` 下用 `:root:not([data-theme="light"])` 重定义，`:root[data-theme="dark"]` 再定义一次；`body` 要显式设背景色。
- 手机宽度（390px）可用：两侧至少 16px 边距，页面不能横向滚动，宽表格和图表放在各自的 `overflow-x: auto` 容器里。
- 字体只从 Google Fonts 引，并写好回退字体栈；脚本只从 cdnjs 或 jsdelivr 引，钉死版本号。图片全部放在本地 `fig/`，不引外链图片。
- 图表按同一个比例尺画，标签只写图上真实出现的数值，文字颜色取主题变量。
- 页面顶部的导航条由 `tools/build.py` 注入（`<!-- vap:nav -->` 标记之间），不要手写。

## 专题页

放在 `topics/<id>/index.html`，内容包括：按时间排的一条线（这一专题里的核心问题是怎样一步步推进的）、每篇的做法 / 结果 / 疑点，以及横向对照表。链接写成 `../../papers/<slug>/`。

## 发布前检查

- `python3 tools/build.py` 通过，没有断链。
- 用本地服务器打开，看一次桌面宽度和 390px 手机宽度。截手机宽度的图要用 Chrome DevTools Protocol 的设备模拟（`Emulation.setDeviceMetricsOverride`）；Chrome 命令行的 `--window-size=390` 有最小窗口宽度，截出来会被裁切，不能用来判断排版。
