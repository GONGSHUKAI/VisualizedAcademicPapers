Adaptive Door Control

An Adaptive Control Approach for Opening Doors and Drawers Under Uncertainties

在机械臂已经抓住把手的前提下，不需要视觉、不需要先验几何，甚至不需要知道面前是旋转门还是推拉门/抽屉。只靠腕部 6 维力/力矩传感器与速度控制闭环，在开门的同时在线估计允许运动方向 x̂h 与缩放旋转轴（曲率向量）κ̂，并从 Lyapunov 理论证明估计误差与约束方向力/力矩误差同步收敛到零。

  • IEEE T-RO Vol. 32, No. 1, pp. 161–175
  • 出版 2016-02 · DOI 10.1109/TRO.2015.2506154
  • 作者：Y. Karayiannidis, C. Smith, F. E. Viña Barrientos, P. Ögren, D. Kragic

做了什么

针对单自由度（1-DoF）刚性机构，提出基于曲率 κ = 1/r 的统一运动学表述，区分被动旋转抓取（Assumption 1）和刚性固定抓取（Assumption 2）两类抓取，给出带 PI 力/力矩反馈的速度控制律与免投影算子（projection-free）的在线更新律，并补全带速度扰动 δ(t) 的鲁棒误差界分析。

放在专题里看

这是「开门与铰接操作」专题的经典控制学起点（也是 DoorBot 直接引用的代表工作）。它假设「已经抓稳且未上锁」，只解决最纯粹的接触后柔顺运动与约束辨识，不靠任何训练数据或视觉，完全靠物理方程与闭环力反馈。

结果

5 个仿真场景（左/右/下铰链门 r=50 cm、推拉门、抽屉）统一初值全部收敛：固定抓取 1.5 s（开门 7.5 cm）转轴中心误差 1.4 cm，被动抓取 4 s 误差 3.4 cm。7-DoF 真机（ATI Mini45）上，刚性抓取旋转门稳态方向误差 <0.8°、重型推拉门 <0.2°、抽屉 1.2°；但抓不刚性的橱柜把手时误差升至 6°–7°。

最该留意的

方法只覆盖抓取之后的拉开过程，不处理找把手、开锁和推/拉方向判断——初始方向误差必须落在 (-90°, 90°) 内，猜反方向会把门往关的方向顶。真机实验只展示了单次曲线，没有多轮成功率统计，也未披露真机所用的增益参数和恒定速度 vd。

问题 · §I–II

不知道铰链在哪，甚至不知道是旋转还是平移，怎么柔顺地开门？

家庭环境里的门、橱柜、烤箱门、推拉门和抽屉都是单自由度（1-DoF）运动学约束机构，但尺寸、铰链位置、转轴朝向和关节类型（旋转 revolute vs 移动 prismatic）千差万别。靠相机或激光雷达提前建模容易受遮挡、光照和未见结构干扰；而控制中一旦沿受约束方向施加错误运动，刚性接触会瞬间产生危险的内力。

论文将不确定性分成两类：动力学不确定性（门板惯量、铰链摩擦/阻尼）和运动学/几何不确定性（关节类型、门宽、铰链位置与朝向）。这篇工作专攻后者，并指出已有三类方法的核心缺陷：

  • 基于速度测量估计运动方向（Niemeyer & Slotine 1997 等）：在低速启动时速度向量归一化病态（ill-defined），加空间滤波又引入滞后、威胁稳定性；
  • 先采集轨迹拟合圆心、再走柔顺控制（Jain & Kemp 2009、Sturm 等）：估计和控制解耦，没有分析「估计器 + 跟踪 + 力控」联合闭环的稳定性，离线方法还无法应对实时变化的约束；
  • 依赖特殊硬件（关节力矩传感器的 DLR 轻型臂、带离合器的机械臂、触觉灵巧手）：无法直接部署在只提供速度接口和腕部 F/T 传感器的常规工业机械臂上。

方法 · 统一运动学表述 · §III

用曲率 κ = 1/r 统一旋转与平移，避开半径趋于无穷的奇异

设末端坐标系 {e} 与把手坐标系 {h} 重合于抓取点 pe，旋转门绕未知中心 po、单位轴 zo 旋转，径向向量 r ≜ po − pe = (1/κ) yh。关键巧思是不去估计半径 r（推拉门和抽屉时 r → ∞ 会发散），而是直接估计曲率 κ = 1/r 及缩放旋转轴向量 κ ≜ κ zh ∈ ℝ³：

v = r × ωh  ⇒  ω = κv,   P(xh)v = 0,   v = v xhEq. (2)–(5)

其中 P(a) = I3 − a a⊤ 是单位向量 a 的正交补投影矩阵（即把向量投影到受约束平面上）。当机构是推拉门或抽屉时，κ = 0、κ = 0，上述一阶微分运动学公式完全保持连续无奇异。

论文严格区分两种抓取物理假设，对应两套更新律与收敛结论：

Assumption 1 · 被动旋转抓取（Non-fixed Grasp）

末端相对把手无平动（hṗe = 0），但允许绕把手自由转动（如圆柱形可转动把手或欠约束夹持）。此时末端只能通过平动速度 vref 和力反馈 f 感知约束，力矩 τ 不可控（旋转自由度可用于优化机械臂可操作度）。

Assumption 2 · 刚性固定抓取（Fixed Grasp）

末端相对把手既无平动也无转动（hṗe = 0 且 hṘe = 0）。此时把手坐标系 {h} 在末端系 {e} 中的方向 exh 恒定不变，且末端角速度与门转动严格绑定 ωe = ωh = v κ，可以同时控制 3 维力与 3 维力矩。

机械臂层面另有两条前提：Assumption 3 要求至少 6-DoF 覆盖全空间速度映射 q̇ = J+(q) uref；Assumption 4 假定底层速度环响应极快（v ≈ vref）且门体惯性力可忽略，使测量力主要反映运动学约束拉格朗日乘子。

方法 · 自适应速度-力控制律 · §IV-A–B

把估计器嵌进 PI 力控速度环：不需要投影算子，自动保单位模长

无论哪种抓取假设，平动速度参考 vref 形式完全统一：沿当前估计的允许方向 x̂h 以期望标量速度 vd(t) 前进，同时在估计的正交约束空间 P(x̂h) 内施加 PI 力反馈（f̃ = f − fd，通常 fd = 0 以抑制内力）：

vref = vd x̂h − P(x̂h) vf,    vf = αf f̃ + βf ∫0t P(x̂h) f̃ dτEq. (8)–(9)

设真实运动方向 xh 与估计方向 x̂h 夹角为 θ(t)（cos θ = xh⊤ x̂h）。理想速度跟踪（ṽ = 0）下，把误差按 x̂h 及其正交空间分解，立刻得到闭环代数学关系：

v = vd / cos θ,    P(x̂h) vf = −v P(x̂h) xh,    ‖P(x̂h) vf‖ = |vd tan θ|Eq. (14)–(16)

解读这三条等式是整篇论文最漂亮的桥梁：方向估得越偏（|θ| 越大），约束面上的力反馈项 ‖P(x̂h) vf‖ 就越大（按 |tan θ| 增长），且当 |θ| → 90° 时力会无穷大。因此直接用 P(x̂h) vf 驱动 x̂h 转向，就能把「正在产生的约束力」变成修正运动方向的梯度信号！

方案 A（Assumption 1 · 被动抓取）

惯性系下联合更新 x̂h 与 κ̂（Eq. 17–18）：

x̂̇h = −γ vref P(x̂h) vf − vref (x̂h × κ̂)
κ̂̇ = Γκ (x̂h × vref)

其中 vref = sgn(x̂h⊤ vref)‖vref‖ 无需知道真实 xh 即可计算。Proposition 1 证 ‖x̂h(t)‖ ≡ 1；Proposition 2 用 Lyapunov 函数 W(θ, κ̃) = (1 − cos θ) + ½ κ̃⊤ Γκ−1 κ̃ 证明在持续激励（PE，Eq. 22）下 θ → 0，但需 Γκ 足够大才能保证 |θ(t)| 始终小于 π/2，且未证明 κ̂ → κ。

方案 B（Assumption 2 · 固定抓取）

利用 exh 在末端系中为常向量，平动更新律大幅简化（Eq. 23–24），且叠加角速度-力矩控制律（Eq. 26–28）：

ex̂̇h = −γ vd Re⊤ P(x̂h) vf,   x̂h = Re ex̂h
ωref = vd κ̂ − ωτ,   κ̂̇ = −vd Γκ ωτ

Proposition 4 得出极简标量微分方程 θ̇ = −γ vd2 tan θ，借对数障碍函数 U(θ) = −log(cos θ) 保证任意 |θ(0)| < π/2 下 θ(t) 永不越界且指数收敛到 0！Theorem 2 进一步证明 τ̃ → 0、κ̂ → κ、ωe → vd κ。

解读为什么方案 B 比方案 A 快一倍且没有超调？

方案 A 里门在转、xh 在惯性系里也跟着转，估计器必须边追 xh 边猜旋转角速度 κ̂，形成二阶耦合振荡（Eq. 20–21）；方案 B 把估计放到随门一起转的末端坐标系 {e} 里，真实方向 exh 变成静止靶子，平动方程退化成一阶单调衰减 θ̇ = −γ vd2 tan θ，同时由 3 维力矩误差 τ̃ 单独驱动 κ̂ 收敛。

方法 · 鲁棒界与在线关节判别 · §IV-D–E

当底层速度跟踪有误差或把手不够硬时，误差会停在哪里？

真实机器人不可能完美满足 Assumption 4。论文在 §IV-D 引入速度级扰动 v = vref + δ(t)（涵盖底层跟踪滞后、抓取/把手弹性形变），对方案 B 推导出带扰动微分方程（Eq. 31）与一致最终有界（UUB）误差界（Proposition 6）：

Ω = { θ ∈ (−π/2, π/2) : |θ| < arcsin λ(t) },    λ(t) = |n′⊤ δ(t)| / |vd|Eq. (32)

其中 n′ 是位于 xh 与 x̂h 平面内的受约束单位方向。这给出了一条非常实用的物理直觉：沿运动方向 xh 的速度扰动完全不影响方向辨识（λ = 0，误差仍趋于零）；真正制造稳态角度偏差的，是受约束方向上的速度扰动与期望速度之比 |n′⊤ δ| / |vd|——这正是真机抓弹性把手时出现 6°–7° 稳态误差的理论根源。

此外，只要得到收敛的 x̂h 与 κ̂，Algorithm 1 就能在运行中任意时刻反推出关节类型与旋转中心：

while Not Done:
  if ‖κ̂‖ > 0.1:             # 曲率 > 0.1 m⁻¹（即等效半径 < 10 m）判定为旋转门
    ρ̂  := ‖κ̂‖⁻¹             # 估计半径
    ŷh := ρ̂ κ̂ × x̂h          # 指向铰链的单位径向
    p̂o := pe + ρ̂ ŷh         # 旋转中心（铰链位置）
  else:
    Sliding door or drawer   # 推拉门或抽屉

实验设置 · §V–VI

5 个仿真机构 + 1 台 7-DoF 工业级机械臂测 3 类真机机构

  • 仿真（§V）：5 个家庭常见机构（左铰链门、右铰链门、下铰链烤箱门，半径均为 50 cm / κ = 2 m−1；推拉门 κ = 0；抽屉 κ = 0）。全部使用同一套初值（κ̂(0) = 0，x̂h(0) 偏离门板法线 30°，对应初始角度误差 20° / 40° / 32° / 60° / 30°）和同一套增益：αf = ατ = 0.05，βf = βτ = 0.005，γ = γκ = 2000，期望速度 vd = 5(1 − e−10t) cm/s。
  • 真机硬件（§VI）：150 kg 类人尺寸 7-DoF 速度控制机械臂（速度指令 130 Hz，内部 PID 电流环 2 kHz）、腕部 ATI Mini45 6 轴力/力矩传感器（采样 650 Hz）、二指平行夹爪。
  • 真机测试对象：3 种物理机构（轻质厨房橱柜旋转门、轻质厨房抽屉、大质量重型推拉门），均给 30° 初始方向误差。橱柜门和抽屉分别测试：① 刚性直抓门板（固定抓取）、② 抓原装不刚性把手（固定抓取抗扰测试）、③ 装自制圆柱被动旋转把手（验证 Assumption 1）。重型推拉门把手本身很刚性，只测固定抓取。
  • 未披露项：真机实验所用的恒定速度 vd 数值、控制增益、各门的实际半径与质量，以及每种条件重复测试次数均未披露（文中只展示单条时间曲线）。

仿真曲线：固定抓取（1.5 s）vs 被动抓取（4 s）

使用完全相同的增益（γ = γκ = 2000），固定抓取在 0.2 s 内即满足 ‖κ̂‖ > 0.1 识别出旋转门，1.5 s（开门 7.5 cm）时旋转中心估计误差仅 1.4 cm，力误差峰值约 0.41 N、力矩误差峰值约 1.1 Nm 后平滑归零。被动抓取虽然在仿真中 κ̂ 也收敛（尽管 Theorem 1 并未从理论上保证它收敛），但收敛耗时翻倍（4 s 才降到旋转中心误差 3.4 cm），且 0.5 s 处出现明显超调（|θ| 折角反弹，κ̃ 峰值飙升到 ±18 m−1）。

真机曲线：刚性假设被打破时会发生什么

真机最有价值的一组对照是橱柜门和抽屉上的「红虚线（直抓刚性门板）vs 蓝实线（抓松软把手）」：刚性直抓旋转门时 |θ| 收敛到 <0.8°、κ̃ 到 0.033 m−1；换抓松软把手后，虽仍能安全把门拉开（且松软把手反而像阻尼器让力误差 ef 更快下降），但方向稳态误差升到 7°、κ̃ 升到 0.16 m−1。抽屉上现象一致：直抓 1.2°，抓把手初期甚至先冲高到 ~55° 再落到 6°。相反，改用圆柱被动把手（不施力矩，走 Assumption 1 控制律）时，旋转门和抽屉分别回到 0.9° 和 0.4°。

读懂它

这篇 2016 年 T-RO 留下了哪几个至今好用的设计？

关键 insight

1. 曲率 κ = 1/r 是统一的正确参数化

旋转门半径有限、推拉门半径无穷大，传统圆心/半径参数化必须先分类再拟合。改用曲率向量 κ = κ zh 后，旋转与平移变成同一连续空间里的 κ ≠ 0 与 κ = 0，同一个控制器无切换通吃两类机构。

2. 在末端坐标系更新方向，把时变问题变静态

固定抓取时把手在末端系 {e} 里相对静止，把自适应律写进 {e} 系（Eq. 24）后，门转弯带来的几何旋转项 −vref x̂h × κ̂ 瞬间消失，误差方程退化成指数稳定的一阶系统 θ̇ = −γ vd2 tan θ。

3. 把「估计」与「柔顺力控」合进同一个 Lyapunov 函数

不是先估完再控，也不是靠外部阻抗硬扛估计误差；约束面上的 PI 力误差直接充当估计器梯度，且自动保持 ‖x̂h‖ ≡ 1，无需人为设投影边界，极大放宽了初始不确定性范围。

4. 刚性 vs 柔顺把手的实证权衡

不刚性的家用把手会引入约束方向弹性速度扰动 δ⊥，虽降低峰值力、依然能安全开门，但会按 arcsin(|n′⊤δ|/|vd|) 抬高几何辨识的稳态误差——如果要精确算铰链位置，刚性抓取很重要；如果只想开门，弹性反而帮忙。

容易误解的地方

  • 它不是一套完整的「自主开门系统」。它假设机械臂已经抓稳把手、门锁已经解开，且外部给了一个与真实方向夹角小于 90° 的初始推/拉方向；找门、抓把手、拧锁、何时停下（需要外部感知或结合辨识角度）和穿过门都不在算法覆盖内。
  • 它不能自动区分推门还是拉门。如果初始估计与真实方向相反（|θ(0)| > 90°），控制器会朝关门方向顶。作者在 §IV-E 明确说明这需要外层监控器检测力过大后停机反向重试（而 9 年后的 DoorBot 正是把这件事做成了闭环状态机）。
  • Assumption 1 的 κ̂ 收敛没有理论保证。虽然仿真里 4 s 后 κ̂ 也趋近了真值，但论文 §IV-E 诚实写明：被动抓取下只证明了方向 x̂h 收敛，没有证明 κ̂ 收敛。

FAQ

如果初始估计恰好垂直于真实方向（例如猜推拉门去拉抽屉，θ(0) = 90°）会怎样？

θ = ±90° 是理论边界（cos θ = 0 导致力无穷大），控制器无法走出奇点。论文在 §IV-E 和 §V 的实际解法非常巧妙：把初始估计故意设在偏离门板法线 30° 的斜方向上，这样无论面对旋转门、推拉门还是抽屉，初始误差都落在 20°–60° 之间，严格满足 |θ(0)| < 90°。

只靠腕部 F/T 传感器，怎么防止机械臂撞坏门或超出关节限位？

论文假设机械臂在开门全程处于无奇异、未触限位的 6-DoF 工作空间内（Assumption 3），且固定底座不移动。实际真机上因重型推拉门靠近奇异点与摩擦限制，只能把全程恒定速度 vd 调低，导致推拉门耗时 20 s。

现在都有端到端 RL 和 VLA 了，这套经典控制律还有什么用？

它不需要任何仿真资产、视觉外观或训练数据，130 Hz 实时闭环且有严格的力/力矩上界保证。在低层作为「柔顺开门技能原语」嵌入高层 VLM/状态机（类似 DoorBot 的架构），或用于真机采集无卡死示教轨迹，依然非常干净可靠。

局限与疑点

作者承认的，和我们读出来的

论文自己承认的局限（§III–VI）

  • 初始估计与真实方向不能垂直或反向（|θ(0)| ≥ 90° 会失效或往关门方向推，需外层监控力阈值并重试）。
  • 被动旋转抓取（Assumption 1）无法控制力矩，也无法从理论上保证曲率 κ̂ 收敛到真值。
  • 算法本身不判断何时把门开到位，需要外部感知（或利用辨识出的铰链与角度估计）发出停止指令。
  • 高度依赖门体不可形变与抓取刚性；家用橱柜/抽屉的不刚性把手会明显拉大估计稳态误差（6°–7°）。
  • 仅处理已抓稳的 1-DoF 机构，未涉及多自由度连动（如先拧下门把手解锁、再拉门）。

我们读出来的疑点

  • 疑点真机实验关键参数缺失：§VI 没有给出真机使用的恒定速度 vd、增益 αf/βf/γ/Γκ、三个门的实际尺寸与旋转半径，也没有报告重复试验次数或成功率，所有真机图均为单条运行曲线。
  • 疑点真机被动抓取未报告 κ̃：虽然仿真 Fig. 3 同时画了 |θ| 和 κ̃，但真机被动把手实验（Fig. 13–16）只画了方向误差 |θ| 和力误差 ef，没有展示真机上被动抓取能否辨识出铰链位置/曲率。
  • 疑点缺少与同表基线的定量对比：Table I 列了 13 篇前作做特性打勾对比，但仿真与真机都没有把任一前作（如 Niemeyer & Slotine 1997 或 Jain & Kemp 2009）跑在同一套门上比收敛速度或峰值力。
  • 细微笔误：Fig. 2 子图标签为 (a)–(e)，图注文字写成 (i)–(v)。

Revolute / Prismatic
旋转关节（铰链门、烤箱门，运动轨迹为圆弧）与移动关节（推拉门、抽屉，运动轨迹为直线）。
Handle Frame {h}
固连在把手接触点的任务坐标系：xh 为允许运动方向，yh 指向铰链，zh 为转轴方向。
曲率向量 κ
定义为 κ = κ zh，其中标量 κ = 1/r 是圆弧半径的倒数；移动关节对应 κ = 0。
P(a) = I3 − aa⊤
投影到单位向量 a 正交补空间的矩阵，用来提取垂直于估计运动方向的约束力分量。
Assumption 1 / 2
1：末端与把手无相对平动但可相对转动（被动旋转抓取）；2：无相对平动也无相对转动（刚性固定抓取）。
PE（持续激励）
Persistent Excitation，要求期望速度平方在任意时间窗内积分有正下界（Eq. 22），保证参数辨识持续获得信息并收敛。
UUB（一致最终有界）
Uniformly Ultimately Bounded，存在持续速度扰动时误差虽不归零，但必定进入并停留在界域 |θ| < arcsin λ(t) 内。
Barbalat 引理
非自治系统稳定性分析常用工具：若 Lyapunov 函数下有界、导数半负定且二阶导数有界，则导数趋于零。
