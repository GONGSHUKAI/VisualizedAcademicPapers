τ0-VLA

a Hierarchical Robot Foundation Model with World-Model-Guided Test-Time Computation

长程任务里最要命的不是动作做不准，而是选错了下一个子任务。τ₀-VLA 的高层先读执行记忆提出子任务；对把握不大的决策，再展开一次「提议 → 想象 → 评分」的束搜索：世界模型画出每个候选子任务完成时的画面，价值模型打分，反思模型综合后才把子任务交给低层 VLA 执行。

做了什么

高层：四个模型。提议模型和价值、反思模型都从 Qwen3.5-9B 微调，世界模型从图像编辑模型 Step1X-Edit 训练。低层：Qwen3.5-2B + MoT 动作专家，40 维统一状态/动作空间，在 40,115 小时真机数据上训练。高层每约 1 秒刷新一次子任务，低层以约 30 Hz 执行。

放在 Harness 里看

两类都沾：子任务 + 执行记忆是「结构化执行」的接口；它的核心贡献是「评估与反馈」：在执行之前用想象的后果给候选打分，而不是等执行出错再补救。执行后的真实观测再写回记忆，形成闭环。

结果

四个长程真机任务，仅加分层与记忆（不搜索）平均成功率 27.5% → 45.0%；开启搜索后三项任务成功次数 5→7、6→9、5→7（每格 10 次）。离线下一子任务准确率，书本整理分布外 50.0% → 74.0%。

最该留意的

每格只有 10 次试验。实际用的 N、B、D 和搜索耗时都没给，只给了 PFLOPs。评测协议提到「记忆消融」，但没有结果。基线怎么微调没说。两张图里同一个 Plan Once 基线数字对不上。

问题 · §1

做错的子任务，执行得再完美也没用

打扫房间、做饭、调饮品这类任务要持续几分钟到十几分钟，由一连串有后果的决策组成：机器人要随时判断哪些已经完成、还剩什么、现在该做哪个子任务。论文的观察是：

  • 多数分层 VLA（π0.5、Hi Robot、GR00T 等）的高层每次决策只做一次前向，直接从当前观测和历史映射到下一个子任务，不比较候选，也不看候选会导致什么状态；
  • 没有执行前的评估，错误只能在执行改变了环境之后才被发现，重规划能响应，但收不回失败承诺的代价；
  • 动作层面的搜索只能看到局部物理后果，纯语言推理能看很远但不落地。子任务介于两者之间：足够稀疏，值得多花算力；又足够长，执行后的状态变化看得出来。

所以论文把「生成下一个子任务」当成一个可以按难度分配算力的推理问题，类似语言模型的测试时计算（o1、DeepSeek-R1）。

方法 · 分层结构 · §3–4.1

高层决定「做哪个」，低层决定「怎么做」

低层 VLA 把多视角观测 ot、本体状态 st、语言指令 ct 和控制元数据 η（本体类型、控制模式、是否全身控制）映射为 H 步动作块。直接执行时 ct 就是整句任务指令 ℓ。分层时，高层策略 μ 每一步读取：

ht = (ℓ, 𝓜t−1, z⋆t−1, ot),   (𝓜t, z⋆t) = μ(ht),   at:t+H−1 = πθ(ot, st, z⋆t, η)(2–4)

𝓜 是执行记忆，z⋆ 是当前子任务。若新子任务和上一步相同，低层继续执行；不同，低层就开始执行新的子任务。部署时两层异步流水：后台进程约每 1 秒刷新一次缓存的子任务，控制循环以约 30 Hz 读缓存出动作，高层慢或失败只会推迟子任务的刷新。

方法 · 世界模型引导的测试时计算 · §4.2 · 附录 C

四个模型，一个束搜索

提议模型 P · Qwen3.5-9B

更新记忆，提出子任务

(zdirt, 𝓜t) = P(ht)。输出 <think> / <memory> / <subtask> 三段。同一次前向的 token 置信度决定是否启动搜索。

世界模型 𝒲 · Step1X-Edit 初始化

想象子任务完成时的画面

ô = 𝒲(õ, z)：输入一张头部相机图和候选子任务，输出子任务结束时的头部相机图。用真实示范里子任务起止两帧训练。

价值模型 V · Qwen3.5-9B

看想象画面打分

v = V(ℓ, z, ô)。做成五选一的 VQA：从「明显错误」到「明显正确」，映射到 0.05–0.95。

反思模型 F · Qwen3.5-9B

综合保留的分支

z⋆ = F(h̄t, 𝒞t)。读真实上下文和最终束里每条分支的子任务序列、想象终态、累计分数。输出可以不在候选集里。

束搜索。根分支的上下文是 ht。在每一层 d，对每个保留分支独立调用提议模型 N 次；对每个候选，世界模型从该分支的画面（根用真实头部图，其余用上一层的想象图）想象结果，价值模型打分，累计分数 S(b ⊕ z) = S(b) + v。所有子分支按累计分数全局取 top-B，扩展到深度 D。分支内的记忆只在分支里用，不覆盖真实的执行记忆。

自适应路由。从提议模型的同一次前向取两个统计量：所有生成 token 的平均概率 uall，以及 <memory> 段 token 的平均 logit 差（第一名减第二名）umem。任一低于阈值就进搜索：

gt = 𝟙[ uallt ≤ δall ∨ umemt ≤ δmem ]附录 C.3

统计量和规则各任务共用，阈值在每个任务的留出数据上单独校准。论文没有报告实际有多少比例的决策进了搜索。

解读搜索比较的是「想象出来的画面」

价值模型从来不看真实的未来，它看的是世界模型从一张头部相机图编辑出的终态图。这有两个风险：世界模型画错了，价值模型就基于错误画面打分；深度 ≥ 2 时，下一层是在想象图上继续想象，误差会累积。反思模型的作用之一是在最后用真实上下文把关，它的输出可以不在候选集里。论文没有评估世界模型想象的准确性。

方法 · 低层策略 · §4.3 · §5.2 · 附录 B.2

一个 VLA，40 维统一动作空间

低层是 Qwen3.5-2B 视觉语言主干 + MoT 动作专家（每个全注意力层里动作 token 和主干 token 共同注意，参数分开），条件 flow matching 训练，动作块 H = 30，10 步 Euler 积分。不同本体都映射到 40 维状态/动作空间，用逐样本掩码选有效通道，掩码同时作用在加噪路径和损失上。

末端动作是相对当前位姿的增量（位置增量在当前末端坐标系下），关节动作是相对当前关节角的偏移。每臂不足 8 个关节的从前往后填，其余掩掉。

三阶段训练

① 知识隔离共训：动作损失的梯度在主干接口处截断，同时训练多模态数据。② 端到端共训：去掉隔离，保留多模态数据作辅助。③ 任务特定适配：每个部署任务用少量示范微调（条数未披露）。

40,115 小时数据

自采约 23.4K 小时：AGIBOT G1 21.9K、G2 585、ARX AC One 578、Franka 347；公开数据约 16.7K 小时，其中开源 UMI 数据 9.25K。另外穿插视觉语言数据（指令跟随、定位、空间与深度推理）。

读懂它

这篇真正说明了什么

关键 insight

1. 在「子任务」这一层花算力

动作层搜索只能看到局部后果，纯语言推理看得远但不落地。子任务稀疏，值得多算；时间足够长，结果在画面上看得出来，可以用世界模型想象、用价值模型比较。这是论文最核心的设计论点。

2. 执行前评估，减少「错误承诺」

MotorMind、TT-VLA 都是执行后才知道对错。τ₀ 在子任务提交之前先比较候选的后果。代价是要训练一个世界模型和一个价值模型，评估的是想象，不是现实。

3. 记忆是长程任务的刚需

加盐这种「做了但看不出来」的步骤，单看当前画面无法判断是否完成。分层系统把番茄炒蛋从 0/10 提到 4/10。记忆扰动的数据构造（滞后、超前、未察觉的失败）不需要额外标注，是可以复用的做法。

4. 按置信度决定要不要搜索

多数决策直接用提议模型的输出，只有 token 置信度低时才搜索。这让「多花算力」变成按需分配，但阈值是逐任务校准的，进搜索的比例也没报告。

容易误解的地方

  • 主表的分层系统没开搜索。27.5% → 45.0% 来自分层和记忆；搜索的闭环效果只在另外三个任务、每格 10 次上测过。
  • 「成功」允许重试。子任务失败后自主重试成功仍记为成功，只在进度分里扣半分。
  • 离线准确率由 GPT-5.4 判定。「等价」要求手臂、动作、物体、目的地都一致，「相邻」（顺序可交换的合理步骤）不算对。
  • 世界模型只看一张头部相机图。不看腕部相机，也不看本体状态。

FAQ

Best-of-N 和 TTC 都用同样的世界模型和价值模型，差别在哪？

Best-of-N 只采一层候选，按价值模型的分数直接选最高的。TTC 多了两样：多层展开（看几步之后的想象状态，用累计分数排序），以及反思模型（读保留分支的路径、想象终态和分数，重新生成子任务，可以修正候选的措辞或选择不在候选里的子任务）。离线准确率上 TTC 比 Best-of-N 高 5–17 个点。

价值模型怎么训练？用的标签从哪来？

先用提议模型和世界模型从真实观测出发反复交替，生成多步的想象轨迹，作为离线数据集。每个候选对照该状态的真实下一步来打五档标签。反思模型用同样的离线轨迹，目标是真实的下一个子任务。所以两者学的都是「接近示范里的下一步」，而不是任务回报。

和 π0.7 的世界模型有什么不同？

论文相关工作里的区分：π0.7 的世界模型为已经选定的子任务生成子目标图像，影响的是「怎么执行」；τ₀ 在提交之前对多个候选想象后果，影响的是「执行哪个」。

为什么书本整理适合测搜索？

四本书按高矮排序，每步交换两本。初始排列不同，正确的交换顺序就不同，没有固定的计划可背。分布外初始排列没在训练中出现过，Plan Once 只有 50%，搜索到 74%；闭环 6/10 → 9/10，是三个任务里提升最大的。

局限与疑点

「执行前评估」的代表

在 Harness for Robotics 专题里，τ₀ 属于评估与反馈：评价信号来自世界模型和价值模型，作用在尚未执行的子任务上；执行后的真实观测通过记忆写回，形成闭环。它同时具备结构化执行的骨架：任务 → 子任务（语言接口）→ 动作块。

  • 和 MotorMind：两者的高层都在做「下一步做什么、做完没有」，都有执行记忆。MotorMind 的诊断显示通用 VLM 判断进度只有 43–76% 准确，τ₀ 的做法是专门训练记忆更新，并用扰动数据教它纠错。MotorMind 不训练、靠执行后的检查和重试；τ₀ 训练、靠执行前的搜索。
  • 和 TT-VLA：同属评估与反馈，但一个在承诺前、在子任务层，一个在承诺后、在动作层。两者可以叠加：τ₀ 选对子任务，TT-VLA 在执行这个子任务时微调动作。不过 τ₀ 的低层是 flow matching，TT-VLA 目前用不上。
  • 和 ACoT-VLA：τ₀ 的子任务接口正是 ACoT 批评的「语言 CoT」。但两者处理的时间尺度不同：ACoT 的参考轨迹只覆盖未来约 3 秒，τ₀ 的子任务要持续几十秒。ACoT 式的动作草稿完全可以放进 τ₀ 的低层。
